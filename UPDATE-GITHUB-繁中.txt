第七版 GitHub Desktop 更新步驟

1. 將 MAA-macOS13-seventh-build-patch.zip 下載至「下載」資料夾並解壓。
2. 開啟 GitHub Desktop，左上角 Current Repository（目前倉庫）選 MAA-macOS13，
   Current Branch（目前分支）選 main。
3. 按 Fetch origin（取得遠端更新）；若出現 Pull origin（拉取遠端更新）則先點擊同步。
4. 選擇 GitHub Desktop 選單 Repository（倉庫）→ Open in Terminal（在終端機開啟）。
5. 執行：
   ditto "$HOME/Downloads/MAA-macOS13-seventh-build-patch/MAA-macOS13" .
6. 回到 Changes（變更），核對 scripts/build.sh，Summary（提交摘要）輸入：
   Fix duplicate MaaCore module map in Xcode build
7. 點 Commit to main（提交到 main），再按 Push origin（推送到遠端）。
8. 開啟 GitHub 網頁倉庫，按 Actions（自動化工作流程）→ Build MAA for macOS 13
   → Run workflow（執行工作流程）。分支為 main，core_tag 為 v6.21.1，
   再按綠色 Run workflow（確認執行）。
9. 若綠色成功，下載 Artifacts（產出檔案）下的 MAA-macOS13-arm64-candidate；
   若紅色失敗，下載 build-logs ZIP 並上傳。不要對舊提交按 Re-run jobs。

注意：此包是原始碼修補，不是已能執行的 MAA.app。所有已知功能均保留。
