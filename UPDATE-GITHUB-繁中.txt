MAA v6.21.1 / macOS 13 第四次編譯：GitHub Desktop 更新教學

本次只需更新既有倉庫，不需建立新倉庫，也不需要在 Mac 安裝 Xcode。

一、下載和解壓

1. 下載 MAA-macOS13-fourth-build-patch.zip。
2. 在「下載」資料夾雙擊 ZIP 解壓，得到資料夾
   MAA-macOS13-fourth-build-patch，其中包含 MAA-macOS13。
   這是原始碼，不是可執行的 MAA.app。

二、在 GitHub Desktop 同步和覆蓋原始碼

1. 開啟 GitHub Desktop。左上 Current Repository（目前倉庫）選 MAA-macOS13。
2. 上方 Current Branch（目前分支）選 main。
3. 先按 Fetch origin（取得遠端更新）；如果出現 Pull origin（拉取遠端更新），
   再按 Pull origin。這步可避免你之前碰過的「Newer Commits on Remote」。
   若出現 Resolve conflicts（解決衝突），停止合併並提供畫面，不要強制推送。
4. 上方選單 Repository（倉庫）→ Open in Terminal（在終端機開啟）。
5. 將下列整行貼進終端機後按 Return（Enter）：

   ditto "$HOME/Downloads/MAA-macOS13-fourth-build-patch/MAA-macOS13" .

   注意最末尾是空格加英文句點「 . 」，代表目前倉庫。
   指令逐檔合併／覆蓋，不會整個刪掉 src、scripts 目錄。
   若下載位置不是 Downloads，請把 Finder 中解壓後的 MAA-macOS13
   資料夾拖進終端機以取得完整路徑，取代上面第一個引號內的路徑。
6. 回到 GitHub Desktop 左側 Changes（變更），應看到以下修改：
   scripts/prepare_core_headers.py
   src/MaaMacGui/MeoAsstMac/Core/Maa.swift
   README.md、UPDATE-GITHUB-繁中.txt、GUI-changes.diff（說明／差異檔）。
7. 左下 Summary（提交摘要）輸入：Fix Swift import of MaaCore extra APIs
8. 點 Commit to main（提交到 main 分支）。
9. 點 Push origin（推送到遠端）。
   如果再次出現 Newer Commits on Remote（遠端有更新提交），
   點 Fetch（取得）、回主畫面 Pull origin（拉取），再 Push origin。
   不要按 Force push（強制推送）。

三、在 GitHub 網頁啟動第四次編譯

1. 瀏覽器進入既有 MAA-macOS13 GitHub 倉庫。
2. 上方 Actions（自動化工作流程）。
3. 左側 Build MAA for macOS 13（macOS 13 建置工作流程）。
4. 右側 Run workflow（執行工作流程）。
5. Branch（分支）選 main，core_tag 填 v6.21.1。
6. 按綠色 Run workflow（確認執行）。
   這次應該新增執行紀錄；不要對舊紀錄按 Re-run jobs（重新執行舊工作）。

四、檢視結果

綠色勾號＝已編譯並打包。
  點執行紀錄，下方 Artifacts（產出檔案）下載
  MAA-macOS13-arm64-candidate。先解壓 artifact，
  再解壓裡面的 App ZIP，得到 MAA.app，在獨立資料夾測試。

紅色叉號＝仍有編譯或建置錯誤。
  點執行紀錄，下方 Artifacts（產出檔案）下載 build-logs，
  上傳完整 ZIP。這次新增：
    core-c-import-check.txt：C 橋接的語法檢查。
    core-swift-import-check.txt：Swift 能否讀到 C 橋接。
  若未執行到該階段，這兩個檔案可能不存在，build.log 仍會保留。

五、實機驗證

編譯成功不等於已確認 macOS 13.7.4 可用。先備份原本設定，
把新 MAA.app 放在另一資料夾啟動，不要直接取代既有版本。
依序檢查 GUI 啟動、設定、核心資源、連線、任務及日誌。
