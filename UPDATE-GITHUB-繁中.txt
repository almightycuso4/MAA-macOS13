第八版 GitHub Desktop 更新步驟（不需先解壓 ZIP）

1. 下載 MAA-macOS13-eighth-build-patch.zip，保存在 Mac「下載」資料夾。
2. 開啟 GitHub Desktop。Current Repository（目前倉庫）選 MAA-macOS13；
   Current Branch（目前分支）選 main。
3. 按 Fetch origin（取得遠端更新）。若變成 Pull origin（拉取遠端更新），先點擊完成同步。
4. 選單 Repository（倉庫）→ Open in Terminal（在終端機開啟）。
5. 逐行貼上以下三行（直接解壓 ZIP 到固定位置，再覆蓋本機倉庫）：

   mkdir -p "$HOME/Downloads/MAA-macOS13-eighth-update"
   ditto -x -k "$HOME/Downloads/MAA-macOS13-eighth-build-patch.zip" "$HOME/Downloads/MAA-macOS13-eighth-update"
   ditto "$HOME/Downloads/MAA-macOS13-eighth-update/MAA-macOS13" .

   注意第 3 行最後的「.」代表目前的倉庫目錄，不能省略。
6. 回到 GitHub Desktop 的 Changes（變更），確認看得到 scripts/build.sh、
   scripts/fetch_core_headers.py、tests/test_fetch_core_headers.py 等檔案。
7. Summary（提交摘要）輸入：Avoid full core source tarball download
   按 Commit to main（提交到 main），再按 Push origin（推送到 GitHub）。
8. GitHub 網頁：Actions（自動化工作流程）→ Build MAA for macOS 13 →
   Run workflow（執行工作流程），選 main，core_tag 保持 v6.21.1，
   按綠色 Run workflow（確認執行）。請開新執行，不要按舊紀錄的 Re-run jobs。
9. 綠色勾號：在 Artifacts（產出檔案）下載 MAA-macOS13-arm64-candidate。
   紅色叉號：下載 build-logs ZIP（含 core-header-download.txt 若已進入該階段）並上傳。

本修補包不是可執行的 MAA.app；GitHub Actions 成功前無法宣稱已完成建置。
